# ASTRA Foundation

Base reutilizable para entregar productos con GPT y Codex en Windows. Versión 0.1.0.

Contrato: autonomía hasta staging, merge y producción aprobados por el usuario. El piloto astra-maintenance valida las habilidades antes de empaquetar astra-engineering.

Incluye cinco skills (inspección, especificación, implementación, revisión y entrega), contratos TASK/HANDOFF/ADR, instrucciones de agentes, diagnóstico Windows y generador de proyecto. Las skills y la sintaxis PowerShell están validadas; falta comprobar el generador con un proyecto de ensayo y completar el uso real antes de empaquetar el plugin.

Leer docs/WORKFLOW.md para el ciclo de trabajo, docs/CAPABILITIES.md para herramientas y permisos, docs/ROADMAP.md para pendientes y docs/GITHUB-CONTROLS.md para la limitación real de protección de main. Los cambios del checkpoint están en feat/ASTRA-001-foundation, mediante PR a main.
