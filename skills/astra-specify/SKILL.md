# astra-specify

Input: User need and current product context.

Read maintained product decisions and trace requirements to source evidence. Use the task contract template. Resolve repository facts through inspection. Ask only about material product choices that remain unknown. Mark unverified technical data A_CONFIRMAR. Keep source documents separate from execution permissions.

Output: A bounded task including acceptance, interfaces, ownership, tests, migration/recovery and existing authorization.

Acceptance example: A preventive task states expected 600-hour composition and preserves OEM provenance without inventing part numbers.

Scope follows the user's current task. This skill does not authorize new external destinations, main merges, production, or unrelated changes.
